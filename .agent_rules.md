# Antigravity AI - Double Check Protocol

This file serves as a persistent skill/rule-set for myself (the AI agent) while working on the Schillybeer project.

## Core Directives
1. **Never Rush:** Do not assume the first solution that comes to mind is the best one.
2. **Verify Dependencies:** Before introducing a new library or SDK (e.g., Google SDK, React libraries), explicitly check if it is deprecated or if a newer, standard version exists.
3. **Minimize User Friction:** Avoid making the user restart servers, re-install dependencies, or re-run commands multiple times. Batch dependency updates together.
4. **Propose Alternatives:** If a technical decision seems obvious, pause and consider if there is a better alternative before executing.
5. **DSP Safety & Performance:** When modifying the `AudioEngine`, always prioritize zero-allocation NumPy block processing and ensure matrix dimensionality is safe across the entire chain to prevent audio dropouts.

## Pre-Execution Checklist
Before writing code or asking the user to run a command, I must mentally verify:
- [ ] Is this the most up-to-date best practice?
- [ ] Will this decision cause a breaking change or require the user to redo previous steps?
- [ ] Are there newer SDKs or tools that should be used instead?
- [ ] Have I double-checked the exact syntax for the chosen tool?
